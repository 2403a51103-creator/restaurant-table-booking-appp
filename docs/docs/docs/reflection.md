# Sprint 1 Reflection

## What Went Well

- Team completed the main booking functionality.
- Product backlog was divided into smaller tasks.
- Team members worked on separate features.

## What Was Difficult

- Integrating different features.
- Managing time during the sprint.
- Testing the booking functionality.

## What We Learned

- User stories help divide requirements.
- Sprint planning helps organize development.
- Regular communication improves teamwork.

## Improvement for Next Sprint

The team will start integration testing earlier
and communicate blockers during the Daily Scrum.
