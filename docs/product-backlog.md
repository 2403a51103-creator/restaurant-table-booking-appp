# Product Backlog

## Product Goal

Develop a restaurant booking application that allows customers to
search restaurants, check table availability, reserve tables,
and pre-order food.

## Product Backlog

| ID | User Story | Priority |
|---|---|---|
| US01 | Customer can register/login | High |
| US02 | Customer can search restaurants | High |
| US03 | Customer can view available tables | High |
| US04 | Customer can reserve a table | High |
| US05 | Customer can view menu | Medium |
| US06 | Customer can pre-order food | Medium |
| US07 | Customer receives booking confirmation | Medium |
| US08 | Customer can cancel booking | Low |
